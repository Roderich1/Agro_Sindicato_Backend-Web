# Archivo histórico de guías para IA

Las guías de esta carpeta describen una etapa anterior del MVP basada en una PWA operativa para agricultores. Se conservan como evidencia histórica y no gobiernan trabajo nuevo.

La fuente vigente es [`docs/scope/CURRENT_SCOPE.md`](../scope/CURRENT_SCOPE.md) y su índice está en [`docs/scope/README.md`](../scope/README.md).

Cada guía histórica contiene un banner visible. Puede consultarse para entender contratos legacy, nunca para inferir requisitos actuales.
