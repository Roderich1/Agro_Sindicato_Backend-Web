# SEQ — pregunta única después de cada tarea

**Instrumento:** *Single Ease Question* (Sauro y Dumas, 2009), una escala de 7 puntos, tal como la cita el protocolo (§3.8).

**Texto en español: traducción de trabajo, no validada.**
- No se encontró ni se verificó una versión española publicada y validada del SEQ al preparar este material. Por eso:
  - el texto es el del protocolo F10 (§3.8), sin cambios;
  - su comprensión se comprueba en el piloto (`08_piloto_comprension.md`, §2);
  - en la evidencia se declara como traducción de trabajo.
- Versión: **SEQ-ES-1**.

## Texto que se lee

> «En general, esta tarea fue…»

| 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|
| Muy difícil | | | | | | Muy fácil |

## Cómo se aplica

- Se lee **inmediatamente** después de cada tarea, también si fue un fallo o se abandonó.
- Se muestra la hoja con la escala y la persona dice o señala un número.
- **No se sugiere un valor.** Si no quiere responder, queda en blanco y se registra vacío.
- Se anota en la columna `seq` de la hoja de registro y de `tareas.csv`, con un entero de 1 a 7 o vacío.
- **Análisis:** sólo descriptivo por tarea (n de respuestas, mediana y rango). No hay umbral.
