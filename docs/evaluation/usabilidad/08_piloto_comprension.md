# Sesión piloto: comprobación de comprensión de los instrumentos

**Quién:** una persona ajena al desarrollo, con código **X01**. Sus datos **se excluyen** de los resultados (decisiones de cierre del 2026-10-16, §2).

**Para qué:** comprobar, antes de la muestra final, que las tarjetas, el SEQ y los ítems del SUS se entienden. La versión del SUS (Sevilla-Gonzalez et al., 2020) se validó en México con otra población: su validez **no se traslada automáticamente** a agricultores bolivianos.

## 1. Cómo se hace

1. Se sigue el guion completo (`02_guion_facilitador.md`), como en una sesión real.
2. **Después** del SUS, nunca durante, se hacen las preguntas de §2 y §3. Se anota la respuesta textual, sin nombres.
3. Se mide la duración real de la sesión, para completar la hoja de información.

## 2. Tarjetas y SEQ

Para cada tarjeta, T1–T6 o W1–W5:

> «Con sus palabras, ¿qué le pedía esta tarjeta?»

| Tarjeta | ¿La entendió como se pretendía? (sí / en parte / no) | Respuesta textual |
|---|---|---|
| | | |

Para el SEQ:

> «Cuando le pregunté si la tarea fue difícil o fácil del 1 al 7, ¿qué significaba para usted el 1 y qué el 7?»

Preguntas adicionales:

- ¿Hubo algún ítem que prefirió no responder? ¿Por qué?

## 4. Qué se decide con esto

- Si **todo se entiende**, las versiones TAR-2 (TAR-1 con la precisión de T3 del 2026-10-19, anterior al piloto), SEQ-ES-1 y SUS-ES-1 quedan fijas y se anotan en `README.md`, en el registro de versiones.
- Si **algo no se entiende**:
  1. Se propone el cambio mínimo. Para el SUS, sólo las adaptaciones candidatas registradas (C-1, C-2) u otra con su motivo.
  2. Se registra en `06_cuestionario_SUS_es.md` §5, o en la tarjeta, con la fecha real.
  3. Se sube la versión: TAR-3, SEQ-ES-2 o SUS-ES-2.
  4. Si el cambio fue grande, se repite el piloto con otra persona ajena (X02).
- **Nada cambia una vez empezada la muestra final.** Una incidencia posterior se anota como desviación, no como cambio de instrumento.
- **El piloto no aporta resultados:** su SUS, sus tiempos y sus éxitos no se publican como evaluación. Sólo se publica qué se ajustó y por qué.
