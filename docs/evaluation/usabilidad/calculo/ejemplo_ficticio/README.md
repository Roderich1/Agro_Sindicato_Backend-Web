# EJEMPLO FICTICIO — no es una evaluación ejecutada

Los datos de esta carpeta son **inventados** para comprobar la aritmética de `../calcular_usabilidad.py`. No describen a ninguna persona ni a ninguna sesión. Todos los códigos empiezan por `EJ-`.

**Están fuera de `../../resultados/` a propósito.** El script marca el informe como «EJEMPLO FICTICIO» y se niega a escribirlo dentro de una carpeta `resultados`.

**Casos que cubren**, con sus valores esperados calculados a mano en `../test_calcular_usabilidad.py`:
- todos los niveles de ayuda;
- una intervención del facilitador;
- un abandono, un tiempo agotado y un resultado incorrecto;
- un error crítico con 5/5 éxitos, que da NO CUMPLE;
- una tarea no intentada, que no entra en el denominador;
- un SEQ sin respuesta;
- un SUS incompleto, sin puntaje;
- un participante sin SUS;
- un piloto excluido;
- el criterio Web de 2/2.
